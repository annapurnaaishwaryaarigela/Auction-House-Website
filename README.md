# 🏛️ Auction House - Premium Bidding Platform

## ✨ Features Implemented

### 🚀 Core Features
* **Auction Listing with Filters:** Filter items dynamically by categories (Art & Paintings, Antiques, Jewelry & Watches, Luxury & Automobiles).
* **Interactive Auction Details & Bidding Modal:** View comprehensive item descriptions, live countdown timers, current highest bids, and place real-time interactive bids[span_7](start_span)[span_7](end_span)[span_8](start_span)[span_8](end_span).
* **Responsive Navigation & Hero Section:** Clean modern layout with custom branding, sticky navigation, and attractive hero presentation[span_9](start_span)[span_9](end_span).
* **User Authentication Mockup:** Login/Register button triggers interactive prompt handlers[span_10](start_span)[span_10](end_span)[span_11](start_span)[span_11](end_span).

### 💎 Design Guidelines & Color Palette
Designed following professional, elegant, and auction-focused UI standards[span_12](start_span)[span_12](end_span):
* **Dark Background (`#1A1A2E`):** Provides a high-end luxury feel.
* **Card Background (`#22223b`):** Subtle separation for item cards.
* **Gold Accent (`#D4A574`):** Used for primary buttons, highlights, and active states.
* **Light Gray (`#E8E8F0`):** Crisp readability for descriptions and text[span_13](start_span)[span_13](end_span).
* **Typography:** Elegant pairing of `Playfair Display` (serif headers) and `Inter` (clean body text).
