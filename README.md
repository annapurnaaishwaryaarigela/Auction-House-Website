# 🏛️ Auction House - Premium Bidding Platform

## ✨ Features Implemented

### 🚀 Core Features
* **Auction Listing with Filters:** Filter items dynamically by categories (Art & Paintings, Antiques, Jewelry & Watches, Luxury & Automobiles).
* **Interactive Auction Details & Bidding Modal:** View comprehensive item descriptions, live countdown timers, current highest bids, and place real-time interactive 
* **Responsive Navigation & Hero Section:** Clean modern layout with custom branding, sticky navigation, and attractive hero presentation
* **User Authentication Mockup:** Login/Register button triggers interactive prompt handlers

### 💎 Design Guidelines & Color Palette
Designed following professional, elegant, and auction-focused UI standards
* **Dark Background (`#1A1A2E`):** Provides a high-end luxury feel.
* **Card Background (`#22223b`):** Subtle separation for item cards.
* **Gold Accent (`#D4A574`):** Used for primary buttons, highlights, and active states.
* **Light Gray (`#E8E8F0`):** Crisp readability for descriptions and text
* **Typography:** Elegant pairing of `Playfair Display` (serif headers) and `Inter` (clean body text).

---

## 🛠️ Technologies Used

* **HTML5:** Semantic structure and content layout.
* **CSS3:** Custom styling, Grid & Flexbox layouts, media queries for responsiveness
* **JavaScript (ES6):** Dynamic card rendering, category filtering logic, real-time bid validation, and modal control.
* **FontAwesome:** Icons for UI navigation and categories.
* **Google Fonts:** Playfair Display & Inter.
